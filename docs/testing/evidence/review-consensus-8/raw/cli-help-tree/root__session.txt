Create, list, show, pause, resume, and cancel agent sessions.

Usage:
  consensus session [command]

Available Commands:
  cancel      Cancel and fail a session
  cost        Show session cost breakdown
  create      Create a new agent session
  list        List agent sessions
  logs        Show session iteration history
  message     Send a message to a session's agent
  pause       Pause a running session
  resume      Resume a paused session
  show        Show session details

Flags:
  -h, --help   help for session

Global Flags:
      --api-key string   API key for authentication (env: CONSENSUS_API_KEY)
      --config string    Config file path (default: ./consensus.yaml or ~/.consensus/config.yaml)
      --format string    Output format: table, json, yaml (default "table")
      --quiet            Suppress non-essential output
      --server string    Consensus server base URL (env: CONSENSUS_SERVER, default: http://localhost:8090)

Use "consensus session [command] --help" for more information about a command.
