Run all pending database migrations. This is an alias for 'consensus migrate run'.

The Consensus server auto-migrates on startup. This command enables
deliberate offline migration.

With --db-url, runs directly against the database (offline mode).
Without --db-url, sends requests to the running Consensus server.

Usage:
  consensus migrate [flags]
  consensus migrate [command]

Available Commands:
  create      Create a new migration file
  rollback    Rollback the last migration
  run         Run all pending migrations
  version     Show current schema version

Flags:
      --db-url string   Database URL for direct migration (e.g. sqlite://dev.db)
  -h, --help            help for migrate

Global Flags:
      --api-key string   API key for authentication (env: CONSENSUS_API_KEY)
      --config string    Config file path (default: ./consensus.yaml or ~/.consensus/config.yaml)
      --format string    Output format: table, json, yaml (default "table")
      --quiet            Suppress non-essential output
      --server string    Consensus server base URL (env: CONSENSUS_SERVER, default: http://localhost:8090)

Use "consensus migrate [command] --help" for more information about a command.
