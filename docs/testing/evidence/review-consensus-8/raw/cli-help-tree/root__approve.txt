List, show, approve, and reject pending HITL approval requests.

Without a subcommand, runs interactive approval mode.

Usage:
  consensus approve [flags]
  consensus approve [command]

Available Commands:
  accept      Approve a pending request
  list        List pending approvals
  reject      Reject a pending request
  show        Show approval details

Flags:
  -h, --help                  help for approve
      --modified-sql string   Modified SQL (for 'modified' decision)
      --notes string          Reviewer notes

Global Flags:
      --api-key string   API key for authentication (env: CONSENSUS_API_KEY)
      --config string    Config file path (default: ./consensus.yaml or ~/.consensus/config.yaml)
      --format string    Output format: table, json, yaml (default "table")
      --quiet            Suppress non-essential output
      --server string    Consensus server base URL (env: CONSENSUS_SERVER, default: http://localhost:8090)

Use "consensus approve [command] --help" for more information about a command.
