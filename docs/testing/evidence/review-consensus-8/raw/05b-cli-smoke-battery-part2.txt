$ consensus help
---------------------------------------------------------------------
Consensus is a database-native cognitive architecture for AI agents.

The CLI is a management tool for the Consensus runtime. It handles
operational tasks: starting the server, managing sessions, reviewing
approvals, running migrations, and inspecting system state.

Usage:
  consensus [command]

Available Commands:
  approve     Manage human-in-the-loop approvals
  completion  Generate shell completion script
  config      Manage configuration
  help        Help about any command
  init        Bootstrap a new Consensus instance
  mcp-stdio   Start MCP server over stdin/stdout (SPEC-015 §5.4)
  memory      Inspect agent memory
  migrate     Run database migrations
  models      Manage the model registry
  reject      Reject a pending approval request
  serve       Start the Consensus server
  session     Manage agent sessions
  skill       Inspect available skills
  status      Show system health and metrics
  tool        Inspect available tools
  version     Print the consensus version

Flags:
      --api-key string   API key for authentication (env: CONSENSUS_API_KEY)
      --config string    Config file path (default: ./consensus.yaml or ~/.consensus/config.yaml)
      --format string    Output format: table, json, yaml (default "table")
  -h, --help             help for consensus
      --quiet            Suppress non-essential output
      --server string    Consensus server base URL (env: CONSENSUS_SERVER, default: http://localhost:8090)
  -v, --version          version for consensus

Use "consensus [command] --help" for more information about a command.
