The short answer: it is real, the core works, and it is not yet ready to hand to a stranger or an external agent.
A message really does reach a real model and come back with real answers, durable DB state, token accounting and billing rows — proven independently on three surfaces (control host, bunker-las-01, and a dogfood run on a clean bunker-las-03). The install path works cold on a fresh machine in ~60 s. What is not true yet: multi-turn delivery was broken (one half fixed, one half open), the published API contract lies about 7 of its own routes, the shim surface is unauthenticated, and MCP attach — the thing that would make muster and arbitrary agents useful — does not work at all. Three P0/P1 defects were found and fixed today by the fleet, which is itself the strongest evidence the project is being driven rather than drifting.
