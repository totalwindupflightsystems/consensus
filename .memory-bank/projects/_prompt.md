# Projects Folder Rules

Scope:
- Project-specific durable knowledge (overview, decisions, context, logs).
- Do not store agent-specific reflections (use `.memory-bank/agents/`).
- Do not store cross-project evergreen knowledge (use `.memory-bank/topics/`).

Rules:
- Each project folder MUST have `_index.md` and `_prompt.md`.
- Never store secrets.
