# decision-archaeology-axiom

Reconstruct why choices were made and why the model or team went down a particular path. Traces decisions back through specs, ADRs, plans, code comments, memory bank notes, git history, and agent outputs to build a causal narrative. Load this skill when someone asks "why did we do it this way?" or when a decision's rationale is unclear.
