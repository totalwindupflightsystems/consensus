# axiom-copilot

Always-available interactive copilot for Axiom. Assumes you know nothing. Checks where you are in the Axiom lifecycle, tells you what to do next, survives context compaction, and uses Axiom itself to teach Axiom. Load this skill whenever you are stuck, starting fresh, or need a checkpoint on what to do next in interactive mode.

## When to Load

Load this skill when you need always-available interactive copilot for axiom.
