# axiom-wave

Wave skill for producing Wave-compatible output. Load this skill when using Wave tools to interact with Spaces, write rich content, propose actions, or read comments. Phase 1 focuses on session review, sharing, and basic comments (comment + highlight only).

## When to Load

Load this skill when:
- You need to write rich content to a Wave Space (reports, charts, status pages)
- You need to read comments or action items from a Space
- You want to propose an action for human approval
- You're working in a session that has an associated Wave Space
