# docs-runbooks-axiom

Operational procedure documentation, troubleshooting flowcharts, recovery runbooks, and onboarding runbooks for AI-assisted development teams. Load this skill when creating runbooks, writing operational docs, generating troubleshooting guides, or linking documentation to alerts and SLOs. Designed for the @docs-runbooks-axiom agent but usable by any agent that produces operational documentation.

## When to Load

Load this skill when:
- Creating a new runbook for an alert, incident type, or operational procedure
- Writing operational documentation (deployment, configuration, troubleshooting)
- Generating documentation from specs, incident postmortems, or log patterns
- Linking runbooks to alerts, SLOs, or trace markers
