# Design Spec Readiness Checklist

axiom:trace work_item=dexdat-design-system-01 spec=specs/README.md plan=.memory-bank/work-items/dexdat-design-system-01/plan.md doc=.opencode/skills/dexdat-design-system-axiom/checklists/design-spec-readiness-checklist.md evidence=.memory-bank/work-items/dexdat-design-system-01/verification.md commit=

Use this checklist before claiming a generated project design spec is ready.

- [ ] Surface scope is explicit (web/mobile/tablet/desktop)
- [ ] Fixed doctrine vs project-specific overrides are clearly separated
- [ ] Tokens are specified or intentionally deferred
- [ ] Layout and breakpoint rules are present
- [ ] Component/state rules are present
- [ ] Motion rules are present, including reduced-motion behavior
- [ ] Accessibility minimums are present
- [ ] Platform-specific adaptations are present where needed
- [ ] Open decisions are listed explicitly
- [ ] The output path in `specs/` is named and trace-linked
