## spec-kickoff-axiom

Kick off (or refine) project specs from minimal human input.

What you get:
- A tiered spec-building loop (idea -> battle-tested)
- Option menus + recommended defaults (so users can answer quickly)
- Multi-agent review packs (assumptions, security, adversarial, UX, verification)

Entry point:
- Load the skill: `skill({ name: "spec-kickoff-axiom" })`

- `.opencode/commands/axiom-spec-request.md` (specwriter + spec verifier loop)
- `.opencode/commands/axiom-work-item.md` (meta-plan + plan artifacts)
