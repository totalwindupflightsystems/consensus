# deedee-qa-harness-axiom

Scenario-based QA harness extending AutoTune via Morty templates. Covers scenario registry, diagnostic sub-stages, triage reporting, pluggable runners (shell, pytest, go-test, http-probe, mcp-tool, agent), flakiness detection, per-stage model declaration, and cost-attributed QA runs. Named after Dee Dee from Dexter's Laboratory — the sister who always broke things.
