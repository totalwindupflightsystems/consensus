# privacy-compliance-axiom

PII detection and redaction patterns, data retention policy verification, consent flow validation, and GDPR/CCPA/HIPAA engineering controls for AI-assisted development. Load this skill when reviewing data handling, auditing PII exposure, verifying retention policies, or assessing privacy posture for any project managed by Axiom. Produces a structured privacy review verdict (PASS|WARN|FAIL|BLOCKED) with a score 0-100. Engineering controls only — not legal advice.

## When to Load

Load this skill when:
- Reviewing code that handles user data, personal information, or sensitive categories
- Auditing a repo for PII exposure in logs, memory bank, evidence bundles, or git history
- Verifying data retention policies are implemented correctly
- Assessing consent flow implementations
