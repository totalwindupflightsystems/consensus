# meta-plan-axiom

Portable skill for producing a work item meta-plan + executable plan artifacts.

Outputs (typical)
- `.memory-bank/work-items/<WORK_ITEM_ID>/meta-planning.md`
- `.memory-bank/work-items/<WORK_ITEM_ID>/plan.md`
- `.memory-bank/work-items/<WORK_ITEM_ID>/plan.yaml`

Use
- Ask the agent to load the `meta-plan-axiom` skill and follow its contract.
